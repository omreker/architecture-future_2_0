# Проектирование целевой архитектуры и приоритизация проблем

## Цель

Спроектировать целевую архитектуру «Будущее 2.0» через 1 год и приоритизировать текущие проблемы.

## Артефакты

- [C4 Container Diagram](C4_Container_Future_2_0.puml)
- [Анализ проблемных мест и приоритизация](problems-and-prioritization.md)

## Краткое резюме

Целевая архитектура построена по принципам Data Mesh с выделением доменов (Clinic, Fintech, AI) и общим Self-Service Data Portal.  
Ключевые проблемы текущей архитектуры приоритизированы методом MoSCoW + матрица Эйзенхауэра.
