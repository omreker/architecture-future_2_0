# Разделение системы на домены и моделирование потоков данных

## Цель

Разделить систему «Будущее 2.0» на домены для независимого развития и описать потоки данных, поддерживающие ключевые бизнес-сценарии.

## Артефакты

- [Data Flow Diagram](dfd.md)
- [Обоснование разделения на домены](domain-decomposition.md)

## Краткое резюме

Система разделена на домены Clinic, Fintech, AI и Shared Platform по принципам Data Mesh.  
Медицинские карты и результаты исследований остаются внутри соответствующих доменов и не попадают в аналитическую витрину.  
Интеграция между доменами реализована через Event Bus и Data Products.
