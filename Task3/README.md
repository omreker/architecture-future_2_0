# Технологический радар и роадмап изменений

## Цель

Сформировать технологический радар и роадмап трансформации IT-ландшафта «Будущее 2.0» для поддержки бизнес-целей компании.

## Артефакты

- [Технологический радар](tech-radar.md)
- [Роадмап изменений](roadmap.md)
- [Обоснование изменений](justification.md)

## Краткое резюме

Технологический радар построен по модели Thoughtworks (Adopt / Trial / Assess / Hold).  
Роадмап разбит на 4 этапа с привязкой к бизнес-целям: запуск Self-Service Portal, независимое развитие доменов и обеспечение качества медицинских и финансовых сервисов.
