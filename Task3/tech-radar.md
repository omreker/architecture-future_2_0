# Технологический радар «Будущее 2.0»

Радар построен по классической модели Thoughtworks и отражает текущее состояние + рекомендуемые изменения.

## Adopt (внедряем)

| Технология / Практика | Зачем нужна | Какие бизнес-сценарии поддерживает |
| --- | --- | --- |
| Apache Kafka (Event Bus) | Транспорт сообщений вместо ESB | Независимое развитие доменов, подключение новых бизнесов |
| Kafka Streams / ksqlDB / Flink | Потоковые трансформации и маршрутизация (вместо логики в ESB) | Real-time интеграции между доменами |
| Data Contracts + dbt tests / Great Expectations | ФЛК и контроль качества данных вместо проверок в ESB | Надёжные Data Products, снижение количества ошибок данных |
| Choreography через события | Замена централизованной оркестрации ESB на распределённое взаимодействие | Снижение связанности, ускорение изменений |
| ClickHouse / BigQuery | Быстрые аналитические витрины внутри доменов | Быстрая подготовка отчётности |
| Data Catalog (DataHub / Amundsen) | Обнаружение и владение Data Products | Self-Service Portal |
| Semantic Layer | Единый бизнес-язык для отчётов | Self-service аналитика |
| Terraform + GitOps | Infrastructure as Code | Воспроизводимость и масштабирование инфраструктуры |
| Keycloak + OPA (ABAC) | Управление доступом | Безопасность медицинских и финансовых данных |
| Managed Kubernetes | Оркестрация сервисов | Масштабирование AI и Portal |

## Trial (пилотируем)

| Технология / Практика | Зачем нужна | Какие бизнес-сценарии поддерживает |
| --- | --- | --- |
| dbt / Dataform | Трансформации как код внутри доменов | Независимое развитие аналитики |
| Feature Store (Feast) | Управление признаками для ML | Развитие AI-сервисов |
| Apache Superset / Looker | Self-service BI | Портал самообслуживания |
| Data Contracts | Соглашения между доменами о качестве данных | Надёжная интеграция доменов |

## Assess (оцениваем)

| Технология / Практика | Зачем рассматривать | Потенциальная польза |
| --- | --- | --- |
| Полный Data Mesh tooling | Автоматизация качества и ownership Data Products | Масштабирование экосистемы |
| Vector Database | Поиск по неструктурированным данным | Перспективные AI-сценарии |
| Serverless compute | Снижение стоимости отдельных Data Products | Оптимизация затрат |

## Hold (удерживаем / выводим)

| Технология | Почему убираем / ограничиваем | Когда |
| --- | --- | --- |
| Microsoft SQL Server 2008 (как центральный DWH) | Монолит, устаревшая платформа, высокая связанность | Постепенно в течение года |
| Apache Camel (легаси ESB) | Сложная поддержка, высокая связанность | После запуска Event Bus |
| PowerBuilder | Устаревший стек, дорогая поддержка | По мере замены интерфейсов клиник |
