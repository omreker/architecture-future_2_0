# Проектирование облачной инфраструктуры с IaaS и Terraform

## Цель

Спроектировать и описать автоматизацию развёртывания облачной инфраструктуры для «Будущее 2.0» с использованием Terraform.

## Артефакты

- [Исходный код диаграммы](diagram.drawio)
- Terraform-конфигурация:
  - `main.tf`
  - `variables.tf`
  - `outputs.tf`
  - `terraform.tfvars`
- [Обоснование конфигурации](justification.md)

## Краткое резюме

Инфраструктура описана декларативно с помощью Terraform.  
Управляются: VPC, подсети, NAT Gateway, Security Groups, виртуальные машины доменов и Object Storage.  
Вручную выполняется только первоначальный bootstrap и управление секретами.
