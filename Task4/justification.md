# Обоснование Terraform-конфигурации

## 1. Выбор ресурсов и параметров

### Networking

- VPC + Public/Private Subnets - классическое разделение: публичная подсеть только для Portal (нужен входящий трафик), остальные домены - в private.
- NAT Gateway - безопасный выход в интернет из private-подсети без назначения публичных IP всем машинам.
- Security Groups - принцип least privilege: web-sg открывает только 80/443, internal-sg разрешает трафик только внутри группы.

### Compute

| VM | vCPU | RAM | Disk | Обоснование |
| --- | --- | --- | --- | --- |
| Portal | 4 | 8 GB | 15 GB HDD | Достаточно для Self-Service Portal + API Gateway на старте |
| Clinic | 4 | 8 GB | 15 GB HDD | Операционная нагрузка + аналитическое хранилище |
| Fintech | 4 | 8 GB | 15 GB HDD | Core Banking + аналитика |
| AI | 8 | 16 GB | 20 GB HDD | Более ресурсоёмкие ML-нагрузки |

### Object Storage

Используется для сырых данных, бэкапов, артефактов моделей и Data Products. ACL = private.

## 2. Почему декларативный подход (Terraform)

- Инфраструктура описывается как код и хранится в Git.
- Изменения проходят code review.
- Исключается конфигурационный drift.
- Легко воспроизвести окружения (dev / stage / prod).

## 3. Как подход IaC способствует воспроизводимости и масштабируемости

| Свойство | Как достигается |
| --- | --- |
| Воспроизводимость | Один и тот же код создаёт идентичную инфраструктуру в разных окружениях |
| Масштабируемость | Новый домен добавляется как новый ресурс (или выносится в module) |
| Аудит изменений | Вся история изменений инфраструктуры хранится в Git |
| Быстрый rollback | Достаточно применить предыдущую версию конфигурации |
| Снижение рисков | Минимум ручных действий -> меньше человеческих ошибок при работе с медицинскими и финансовыми данными |

## 4. Что остаётся вручную

- Создание Cloud и Folder

- Создание сервисного аккаунта и назначение IAM-ролей

- Получение ключа сервисного аккаунта (JSON)

- Генерация и размещение SSH-ключей

- Внешние DNS-записи (при необходимости)

Все остальные компоненты (сеть, виртуальные машины, диски, бакеты, security groups) полностью управляются Terraform.
